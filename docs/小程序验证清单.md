# 微信小程序 · 验证清单

小程序无法像 Web 那样直接打开，必须跑在微信开发者工具或真机里。本清单按顺序做，
每步都有明确预期；先做完「接口层」再进工具，可避免在工具里盲目排查。

---

## 一、已自动验证（无需人工）

```bash
cd 白蕉水产养殖管理平台
python tests/check_miniprogram_api.py
```

用 Python 模拟 `wx.request` 逐个调用小程序依赖的接口，覆盖三个页面用到的全部请求。

**当前结果：11 项全部通过。** 说明接口路径、字段名、权限、身份头都正确，
剩下的问题只可能出在「渲染」和「真机环境」。

---

## 二、启动后端（让手机/工具能访问）

小程序**不允许请求 `127.0.0.1`**，必须用局域网 IP。

```bash
# 1) 改 .env
APP_HOST=0.0.0.0

# 2) 启动
python backend/app.py

# 3) 查本机局域网 IP（本机当前为 172.33.13.39，可能变化）
ipconfig | findstr IPv4
```

确认后端确实监听在 0.0.0.0：

```bash
curl http://<你的IP>:5000/health
```

**预期**：返回 `{"ok":true,...}`。若不通，多半是 Windows 防火墙拦了 5000 端口。

---

## 三、指向后端地址

编辑 `miniprogram/utils/api.js`：

```js
const BASE_URL = 'http://172.33.13.39:5000';   // 改成你查到的 IP
```

> 真机预览必须用 IP，不能用 `localhost`——手机的 localhost 是手机自己。

---

## 四、在开发者工具中导入

1. 开发者工具 → **导入项目**
2. 目录选 `白蕉水产养殖管理平台/miniprogram`
3. AppID 选 **「测试号」**（无需注册）
4. 确认 **「不校验合法域名…」已勾选**（`project.config.json` 里 `urlCheck:false` 已默认关闭校验）

**预期**：编译成功，进入鱼塘列表页，**无红色报错**。

## 五、逐页验证

### 页面 1：鱼塘列表（`pages/index`）

| 检查项 | 预期 |
|---|---|
| 列出鱼塘 | 显示「A01 号塘」「A02 号塘」 |
| 副标题 | `A01 · 8亩 · 批次 A01-2026春` |
| 状态标签 | 「终端在线」或「终端离线」（取决于终端是否连接） |
| 点击卡片 | 跳转到单塘看板 |

**若显示「加载失败，请确认后端已启动」** → 回第二步检查 IP 和防火墙。

### 页面 2：单塘看板（`pages/pond`）

| 检查项 | 预期 |
|---|---|
| 标题 | `A01 号塘` |
| 批次 | `批次 A01-2026春 · 海鲈 · 54000 尾` |
| 环境实况 | 水温 / 溶氧 / pH 三项，各带数值+单位+时间 |
| **过期标记** | 若数据超期，时间后应有红色「（已过期）」 |
| 点「规则建议」 | 弹出提示「已生成建议 X kg」，下方出现建议卡片 |
| 点「大模型建议」 | 需后端配 `SILICONFLOW_API_KEY`；未配置会提示「大模型未配置」，不会假装成功 |
| 建议卡片 | 显示建议量、规则版本、**依据文字**（含鱼重、温度、系数） |
| 点「确认并下发」 | 弹出「任务 TK-xxxx 已下发」 |
| 点「生长预测」 | 显示「当前估计 780.8g · 日增 2.889g · 距目标 7 天」 |
| 最近任务 | 列出刚下发的任务号与状态 |

> 生长预测需先训练过模型。未训练时会提示「模型尚未训练」，这是**正确行为**（不返回假数据）。
> 训练命令：`curl -X POST http://<IP>:5000/api/ponds/1/model/train -H "X-User: owner"`

### 页面 3：交流排行（`pages/community`）

| 检查项 | 预期 |
|---|---|
| 排行榜 | 显示 A01/A02；数据不足的标「未参与」+ 原因 |
| 输入标题+内容 | 能输入 |
| 切换分类 | 经验交流 / 问题求助 / 行情信息 |
| 点「发布」 | 提示「已发布」，下方「最新帖子」出现该贴 |
| 帖子行 | 显示标题、分类标签、作者名、回复数 |

## 六、真机预览（最后一步）

开发者工具 → 右上角 **「预览」** → 手机微信扫码。

| 检查项 | 预期 |
|---|---|
| 三个页面都能打开 | 与工具内一致 |
| **布局不溢出** | 无横向滚动，文字不逐字换行 |
| 按钮可点 | 触控区域够大，无「点不中」 |
| 环境数据时间 | 与电脑看板一致 |

**注意**：真机预览 `http://` 会被微信拦截，需要在手机端也允许——工具里勾选
「不校验合法域名」对真机同样生效（预览模式下）。**正式发布必须配 HTTPS 域名**，
这是课程演示与上线的重要区别，README 已如实标注。

## 七、已知限制（如实说明，非缺陷）

- **无 AppID**：用测试号，无法发布上线，只能开发/预览。
- **HTTP 明文**：仅局域网演示可用；上线需 HTTPS + 已备案域名。
- **未真机验证过**：截至 2026-09-13，本清单是人工程序，尚未实际执行过真机流程。

## 八、排查用

| 现象 | 原因 | 处理 |
|---|---|---|
| 全部页面「加载失败」 | IP 错 / 后端未开 0.0.0.0 / 防火墙 | 检查第二节；手机浏览器先访问 `/health` |
| 能列表但单塘空白 | 该塘无环境数据 | 属正常（未接入），跑仿真器或上传测量 |
| 生成建议失败「数据过期」 | 最近水温超有效期 | 上传一条新测量 |
| 「模型尚未训练」 | 未训练 | 调 train 接口，或接受此提示 |
| 确认下发失败「设备已有未结束任务」 | 设备被占用 | 到 Web 端「待核查」页核查释放 |
